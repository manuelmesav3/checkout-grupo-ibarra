# Checkout Grupo Ibarra — Checklist & Validación Interactiva

Herramienta interactiva de seguimiento, auditoría y criterios de aceptación para el flujo de Checkout y funcionalidades asociadas de las tiendas **Grupo Ibarra** (SuBodega e Ibarra Mayoreo).

## 🚀 Inicio rápido

### 1. Requisitos
- Node.js (v18+)
- npm

### 2. Instalación de dependencias
```bash
npm install
```

### 3. Servidor de desarrollo local
```bash
npm run dev
```

### 4. Compilación para producción
```bash
npm run build
```

El build optimizado se generará en el directorio `dist/`.

## 📁 Estructura del Proyecto
- `index.html`: Punto de entrada de la aplicación web (Checklist interactivo).
- `Checklist Ibarra FINAL.html`: Versión canónica e independiente del checklist.
- `package.json`: Configuración y dependencias (Vite).
